# Harness 选型实验结论

## 结论

当前样本不支持把完整 Deep Agents Harness 作为 Research Pulse 单篇论文阅读的默认运行时。

推荐采用：

> 确定性外层工作流 + 受限模型步骤 + 产品自有证据/发布边界。

若固定选材暴露真实 coverage 缺口，再在单个步骤内加入有预算上限的只读检索工具；不先开放完整自主循环。

## 实测结果

| 指标 | 固定 workflow | Deep Agents |
| --- | ---: | ---: |
| 模型 | deepseek-v4-flash | deepseek-v4-flash |
| 墙钟时间 | 60.312 秒 | 126.133 秒 |
| 模型回合 | 1 | 18 |
| 工具调用 | 0 | 35 |
| 总 token | 14,015 | 452,613 |
| 笔记字节数 | 7,307 | 17,892 |
| 引用次数 | 27 | 82 |
| 可直接解析引用有效率 | 100% | 0% |

## 观察

### 固定 workflow

- “问题、核心直觉、方法”已经清楚、具体，并包含真实完整 block ID。
- 单次调用在“实验设置”中途截断；usage 显示 7,002 completion tokens 中有 5,077 reasoning tokens。
- 这是输出预算/步骤划分问题。把“论文理解”和“最终成文”拆成两个有界调用，或进一步缩短中间材料，即可直接验证修复。

### Deep Agents

- 自主检索补到了更多方法细节、实验表格、论文局限和未知项，最终笔记更完整。
- 发生多次重复搜索，也多次把搜索返回的完整 ID 缩短后传给 `read_blocks`，造成无效调用。
- 最终笔记把所有引用写成短 hash（如 `[b19f5a2753ff]`），人眼可以猜测，但产品无法直接解析；因此不满足现有 evidence-first 契约。
- 452,613 tokens 相比固定 workflow 增加约 31.3 倍，远超此前讨论的 pilot 成本边界。

## 设计含义

完整 Harness 擅长在未知任务中自主探索，但单篇论文笔记是一个输出结构稳定、材料边界明确、可预先分阶段的任务。默认开放自主循环会把“模型可以继续搜索”放大为重复搜索和上下文膨胀。

Research Pulse 当前需要保留的不是自研 Harness，而是：

1. 论文材料与稳定 block 身份；
2. 确定性阶段和预算；
3. 引用由系统保存/渲染，不能依赖模型抄写 ID；
4. 笔记草稿、验证、发布和版本边界；
5. 真实浏览器阅读与证据核查体验。

## 推荐的下一实验

只实现一个 `workflow-v2`：

```text
确定性选取导航材料
    ↓
调用 1：形成带 block IDs 的 Paper Understanding
    ↓
按缺口确定性补取方法/实验/局限 blocks
    ↓
调用 2：生成最终可读笔记
    ↓
程序校验引用并发布为 prototype output
```

只有当 `workflow-v2` 在未参与规则设计的新论文上持续漏掉关键章节，才增加一个受限的 `search_paper` agentic step。该 step 必须有最大调用数、最大读取 blocks、最大 token 和 locator receipt。
