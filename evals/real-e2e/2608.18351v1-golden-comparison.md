## 关键遗漏

当前产物至少遗漏或错误处理以下核心事实：

1. 论文要解决的是 task-relative excess-authority，而不是泛泛的“工具智能体有副作用”。
2. 静态权限 gating 可能漏掉等价状态变化，也可能授予任务不需要的敏感权限。
3. 六维向量是 `write / exec / external / secret / scope / persistent`。
4. 任务权限包络只惩罚超过任务需要的部分，不是无条件禁止高风险动作。
5. safe success 同时要求任务成功、证据充分、状态满足且无超额权限事件。
6. 后训练使用 Qwen3.5-4B、rank-32 LoRA、direct Dr. GRPO。
7. Table II 明确给出 base 与 Seed 1 的对照结果。
8. 外部评测和 400-task continuation 提供了有限的泛化证据。

## 这次对照说明了什么

问题不是单纯“再增加几个 source_fact”。当前提取结果已经有足够的局部证据，但生成阶段没有建立跨引言、方法和实验的论文主线；同时，局部证据筛选还把公式、表格和结果上下文挡在了精读过程之外。

因此下一实现实验应验证的是：

> 先建立论文问题—主张—方法地图，再检索和绑定证据，是否能在不增加关键幻觉的情况下恢复完整叙事。

在该实验通过前，不应继续扩展 facet、数字或历史 reconcile 等边缘功能。
