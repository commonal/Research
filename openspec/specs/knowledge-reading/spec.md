# Knowledge Reading

## Purpose

定义知识时间线、当前版本 Markdown 详情、安全渲染、来源可见性和论文范围问答，使用户只阅读可校验的已发布知识，并能明确区分空库、资产不可用与服务失败状态。

## Requirements

### Requirement: 时间线只读取可校验的已发布 Markdown 元数据
系统 SHALL 扫描知识仓中的论文 Markdown，跳过损坏或非发布资产，并为每个知识 ID 最多返回一个版本标识最新的合法发布版本；响应包含标题、知识 ID、版本、领域、证据等级和首个来源 URL。

#### Scenario: 知识仓同时存在发布资产和损坏文件
- **GIVEN** 知识目录包含至少一个合法发布资产和一个无法解析的文件
- **WHEN** 用户请求知识时间线
- **THEN** 响应包含合法发布资产的元数据
- **THEN** 响应不包含损坏文件

#### Scenario: 同一知识存在多个发布版本
- **GIVEN** 同一知识 ID 在知识仓中存在多个通过校验的发布版本
- **WHEN** 用户请求知识时间线
- **THEN** 系统仅返回版本标识最新的发布版本

#### Scenario: 知识仓为空
- **GIVEN** 知识仓中没有可用的发布资产
- **WHEN** 用户打开首页
- **THEN** 系统返回空时间线，前端显示明确标注的引导状态
- **THEN** 前端不得把演示内容标记为真实知识

### Requirement: 用户可以读取当前知识详情
系统 SHALL 按知识 ID 返回当前已发布版本的元数据与完整知识 Markdown 正文，且正文必须通过现有资产结构和内容哈希校验。

#### Scenario: 成功读取已发布知识
- **GIVEN** 指定知识 ID 存在一个可校验的当前发布版本
- **WHEN** 用户从时间线选择该知识
- **THEN** 系统返回该版本的标题、领域、证据等级、版本、来源 URL 和 Markdown 正文
- **THEN** 前端渲染返回的正文，而不是固定演示正文

#### Scenario: 知识不存在或不可发布
- **GIVEN** 指定知识 ID 不存在、仅有草稿、文件损坏或内容哈希校验失败
- **WHEN** 用户请求该知识详情
- **THEN** 系统返回不暴露文件系统细节的未找到响应
- **THEN** 前端显示知识不可用状态，不回退为貌似真实的演示正文

### Requirement: 阅读详情保持来源可见且不夸大定位能力
系统 MUST 保留知识正文中的主张类型与现有锚点字符串，并 SHALL 提供至少一个可访问的来源 URL；前端不得把当前知识 chunk 锚点描述为论文页码或论文来源锚点，也不得通过 Markdown 渲染引入可执行 HTML。

#### Scenario: 展示带当前锚点字符串的知识
- **GIVEN** 已发布 Markdown 包含事实主张及其锚点标识
- **WHEN** 前端渲染知识详情
- **THEN** 主张类型和锚点标识保持可见
- **THEN** 用户可以通过来源链接打开原始来源
- **THEN** 页面不宣称该锚点能够跳转到论文具体位置

#### Scenario: Markdown 包含原始 HTML
- **GIVEN** 知识 Markdown 中出现原始 HTML 或脚本式内容
- **WHEN** 前端渲染知识详情
- **THEN** 系统不得执行该 HTML 或脚本

### Requirement: 前端提供全库与当前论文问答入口
系统 SHALL 允许用户发起全库问答；从“问这篇论文”入口发起时 SHALL 将当前知识 ID 作为检索范围。

#### Scenario: 用户询问当前论文
- **GIVEN** 用户在时间线中选择了一项真实知识
- **WHEN** 用户通过“问这篇论文”提交问题
- **THEN** 前端向问答 API 发送当前知识 ID

### Requirement: 当前论文问答沿用详情范围
系统 SHALL 在用户从知识详情页发起“问这篇论文”时，将当前知识 ID 作为检索范围传给问答接口。

#### Scenario: 从当前论文发起问答
- **GIVEN** 用户正在阅读一个真实知识详情
- **WHEN** 用户点击“问这篇论文”并提交问题
- **THEN** 问答请求包含当前详情的知识 ID
- **THEN** 检索结果限定在该知识范围内

### Requirement: 加载失败状态透明
前端 SHALL 区分详情加载中、知识仓为空、知识未找到和后端不可用，不得用静态正文掩盖这些状态。

#### Scenario: 后端暂时不可用
- **GIVEN** 前端无法连接知识详情 API
- **WHEN** 用户打开或切换知识详情
- **THEN** 前端显示后端不可用提示和重试入口
- **THEN** 前端不得将演示正文展示为所选知识的实际内容

### Requirement: 演示状态不伪造真实问答
系统 SHALL 只在知识仓为空时显示明确标注的非真实知识引导，并 SHALL 在详情或问答请求失败时展示对应错误状态，不生成伪造的知识正文或问答结果。

#### Scenario: 前端无法访问 API
- **GIVEN** FastAPI 未运行
- **WHEN** 用户打开前端或尝试问答
- **THEN** 页面显示服务不可用状态而不是静态论文正文
- **THEN** 问答区域不生成伪造的知识库答案

### Requirement: 阅读页展示证据解析边界而不伪造论文定位

系统 SHALL 在论文精读阅读页向用户展示来源事实的内容类型和已知降级边界；对未解析公式、残缺表格或未解释图片 SHALL 显示不可自动解读提示。页面 MUST 继续区分知识 chunk 锚点与论文来源定位，且不得把缺失页码/bbox 的证据展示为精确页码跳转。

#### Scenario: 阅读页包含未解析公式边界

- **WHEN** 当前知识版本标记一个公式证据为未解析
- **THEN** 页面显示公式未结构化解析的阅读边界，且不显示自动生成的公式解释

#### Scenario: 阅读页加载旧版本资产

- **WHEN** 当前资产缺少增强块元数据
- **THEN** 页面保留既有正文和来源链接，并显示该版本没有增强证据定位而非报错或伪造状态

### Requirement: 阅读页可预览隔离的待审核精读

系统 SHALL 允许论文阅读页读取与当前知识 ID 关联的待审核精读草稿，并同时显示其状态、质量问题、证据边界和来源链接；待审核草稿不得被当作当前正式知识。

#### Scenario: 当前版本存在待审核草稿

- **WHEN** 用户打开一个已有当前发布版本且存在 `needs_review` 草稿的论文详情
- **THEN** 页面同时展示当前正式版本和待审核预览入口
- **THEN** 页面明确标记待审核内容不会进入 RAG 问答

#### Scenario: 当前版本不存在但有待审核草稿

- **WHEN** 知识 ID 只有待审核草稿而没有已发布版本
- **THEN** 页面显示待审核状态和来源链接
- **THEN** 问答入口不可用，不生成正式知识答案
