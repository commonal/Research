# 归档摘要

## 用户可见行为

- 资料架按知识 ID 去重，只展示通过校验的当前已发布版本。
- 用户选择论文后读取 canonical Markdown 详情和来源链接，不再展示固定演示正文。
- 阅读页明确区分加载中、空库、未找到和服务不可用；失败时不会回退为貌似真实的演示知识。
- Markdown 不执行原始 HTML；知识锚点保持普通文本，不宣称能够跳转论文页码。
- “问这篇论文”继续把当前知识 ID 作为检索范围。

## 验证结果

- Python 主测试：50 项通过，无跳过（含 PostgreSQL 集成测试）。
- Worker 测试：6 项通过。
- Markdown 安全检查：通过。
- React TypeScript/Vite 生产构建：通过。
- 浏览器桌面、390px 移动端、快速切换、空库和服务失败状态：通过。
- OpenSpec 严格校验：8 项通过。
