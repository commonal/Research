# 归档摘要

## 用户可见行为

- 用户可以从论文精读首页创建并持久化研究方向，系统生成稳定 topic ID 与隔离 domain。
- 创建方向后立即返回并异步处理最多 3 篇候选；页面展示等待、运行、完成、部分失败或失败状态。
- 运行发布新知识后，前端停止轮询并刷新真实 Markdown 时间线；终态运行支持手动重新抓取。
- 同一方向已有活动运行时不会启动第二批任务，而是复用并展示现有 run。
- 缺少 DeepSeek 时方向仍被保存，运行显示可重试配置错误；API 和数据库不暴露密钥、文件路径、完整异常或 provider 原始响应。
- 服务重启后遗留活动运行会转为可重试失败，原始 PDF、解析全文和提示词仍只存在于单篇临时处理生命周期。
