# 归档摘要

## 用户可见行为

- 同一研究意图始终显示为一张 Run 卡；预算耗尽、网络失败、取消后重启和显式继续会在该 Run 下创建新的不可变 Attempt。
- 用户可以展开 Attempt 历史，查看每次执行的独立状态、预算和安全诊断。
- 继续和取消会校验当前 Attempt 身份并抵抗重复点击或陈旧页面请求。
- 无真实 checkpointer 时，界面诚实显示“基于已有结果继续执行”，不宣称无损恢复。
- 工具失败按参数、临时外部错误、权限配置、领域冲突、取消、预算和未知副作用分别呈现；可修正的单次工具失败不再自动终止整个 Attempt。
- 运行中取消并刷新后仍保持持久终态；HTTP 请求结束不会终止已排队的探索任务。

## 验证结果

- OpenSpec 任务：58/58 完成，严格 change 校验通过。
- Workbench Python：289/289 通过；worker Python：15/15 通过。
- 前端：55/55 通过；TypeScript/Vite 生产构建通过。
- 内容边界专项：26/26 通过；未发现完整论文正文进入数据库、事件或 checkpoint。
- 真实浏览器完成预算耗尽继续、网络失败再继续、最终完成，以及运行中取消后刷新两条生命周期旅程。
- 真实模型/真实研究工具冒烟以 `budget_exhausted` 结束，已作为外部结果诚实保留，未替代确定性合同验收。
