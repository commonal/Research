# 原型阶段回执

日期：2026-08-31

## 结论

V1 工作台产品原型已通过用户验收，可以进入生产接线阶段。用户于 2026-08-31 明确确认“可以验收了”。本回执只证明产品原型旅程与交互门槛，不替代 V0 Harness 的运行时能力验证。

## 已完成

- 建立 `WorkbenchClient` 及 Session、Paper、Message、Context、Citation DTO；fixture 使用 `papers[]` 与 `active_paper_id`。
- 实现工作台/知识库一级切换、历史会话、新建、切换、重命名以及会话级论文布局恢复。
- 支持本地 PDF 上传和公开 PDF URL 输入；添加论文后自动进入左侧对话、右侧论文分屏。
- 使用构建内 PDF.js worker 渲染完整多页 PDF；演示论文 8 页均可查看。
- 工作台占满可用视口；对话区和论文区独立滚动，提问 composer 固定在对话区底部，论文滚动不再带动整页。
- PDF 文本层支持选择；选择动作浮层不参与文档布局，`ResizeObserver` 保持画布、文本层及选择坐标一致。
- 覆盖普通文本、双栏、公式/表格附近选择、有效/无效 B#、引用回跳及 unresolved 状态。
- 用模拟 NoteRun 展示进度、失败、成功和预生成知识笔记链接。

## 真实浏览器证据与摩擦闭环

- 真实浏览器完成：进入工作台 → 新建/切换会话 → 添加论文 → 多页阅读 → 选择论文上下文 → 提问 → 点击引用回到论文。
- 8 页演示论文全部渲染；论文面板 `scrollTop` 从 0 滚动到 1870 时，页面 `scrollY` 始终为 0。
- 720px 高视口中，页面 `scrollHeight` 与视口同为 720px，composer 底边保持在 720px，证明外层页面不滚动且输入区固定。
- 用户实际指出并复验的摩擦点均已闭环：无法输入论文、只能查看首页、页面左右留白、选择区域偏移/自动上移、论文滚动与页面滚动混在一起、提问框未固定到底部。
- 最终验收结论由用户明确确认；不虚构额外受试者身份或论文名称。
