# 论文解读的证据等级

Research Pulse 不把不同证据强度的内容混在一起。每篇 Markdown 都必须记录 `analysis_level`。

| 等级 | 可读取的输入 | 可以写什么 | 不能写什么 |
|---|---|---|---|
| `abstract_only` | 标题、作者、摘要、元数据 | 研究问题、摘要中明示的方法/结果、待核查问题 | 图表、公式、实验细节、真实局限、复现结论 |
| `full_text_text` | 临时下载的 PDF/HTML 正文文本 | 正文段落、实验设置、作者明确陈述的局限 | 只存在于图片中的图表信息；OCR 猜测的公式 |
| `full_text_multimodal` | 正文、可解析公式、关键页渲染图像/图注 | 关键图表作用、公式符号解释、跨章节综合 | 未在来源中支持的因果结论或复现保证 |

## 后续全文路线

1. 临时获取允许访问的 arXiv PDF、HTML 或 LaTex source；长期只保存来源链接和派生 Markdown。
2. 对公式优先读取 LaTex/MathML，而不是把公式图片交给 OCR。
3. 对图表提取图注和相关正文；必要时渲染关键页交给视觉模型，并标注页码/图号。
4. 每个图表、数字和复现判断都保留来源锚点；无法定位时降级为“未验证”。

DeepSeek 的文本聊天 API 适合当前摘要级结构化输出；图表理解需要在后续接入具备视觉输入的模型或专门的文档解析服务。
