### 网络中断失败的根因与修复

Attempt 使用约 5 分钟的 lease。旧实现只调用 `abandon_expired_attempts`，因此刚刚中断且 lease 尚未过期的运行会在一段时间内保持 `running`。现在应用启动时调用 `abandon_running_attempts`，立即将上一个进程遗留的 `running` Attempt 转为 `abandoned`，清除旧 lease，并把 Run 投影为可继续的失败状态；已持久化事件仍保留。

## 2026-09-14 引用高亮精度修复补充

上一轮浏览器验收证明了“引用可点击、可跨页跳转”，但没有证明高亮矩形与 PDF 文本位置足够精确。对真实 DPO4Rec 材料复核后确认：MinerU API 的 `content_list.json` 使用固定 **1000×1000** 页面坐标，而旧前端把它当作 PDF.js 画布像素坐标处理，导致右栏等区域出现明显偏移；同时块级 bbox 会覆盖整段文字，视觉上显得“只是大概位置”。

本轮已完成以下收敛：

| 修复项 | 结果 | 证据 |
| --- | --- | --- |
| 坐标契约显式化 | 通过 | 后端对 `parser=mineru_api` 的材料返回 `bbox_space=normalized_1000` 与 `bbox_dimensions=[1000,1000]`；旧材料继续兼容 `page_points` |
| 前端坐标映射 | 通过 | 客户端按来源坐标空间转换为页面相对坐标，不再根据数值大小猜测 |
| 块级 bbox 细化为逐行高亮 | 通过 | PDF.js 文本层 runs 与粗 bbox 做相交筛选并按行分组，优先渲染多个紧贴文字行的矩形；无文本层时才回退到块级框 |
| 回归测试 | 通过 | 前端坐标映射、逐行高亮、选区匹配共 18 个相关用例通过，完整前端 87 个用例通过；后端 paper API、chat、two-session 共 19 个用例通过；TypeScript 检查与生产构建通过 |

本轮未重新启动生产后端做最终视觉复验：当前 `.env` 指向 `localhost` PostgreSQL，但本机 5432 端口未监听，应用工厂在数据库初始化阶段无法完成。因此，**坐标契约和逐行高亮已由代码及回归测试确认，真实浏览器的最终像素级验收仍需在 PostgreSQL 可用后重新执行**；上一轮的浏览器截图只能作为旧坐标逻辑的基线，不能替代本补丁的最终视觉证据。
